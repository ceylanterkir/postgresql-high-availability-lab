# PostgreSQL High Availability Lab

## Overview

This repository documents a PostgreSQL High Availability
architecture studied during my database administration
internship at Istanbul Metropolitan Municipality (IMM).

The architecture involved the following technologies:

- PostgreSQL
- Patroni
- etcd
- HAProxy
- Keepalived

## Architecture

This section describes the overall architecture
and the role of each component.

## Technologies

| Technology | Purpose |
|---|---|
| PostgreSQL | Relational database |
| Patroni | High availability management |
| etcd | Distributed configuration store |
| HAProxy | Connection routing |
| Keepalived | Virtual IP management |

## Learning Outcomes

- Understanding PostgreSQL HA architecture
- Learning cluster components
- Understanding failover concepts
- Exploring database availability and monitoring
